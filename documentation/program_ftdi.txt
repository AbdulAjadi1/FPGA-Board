This example is done in the Windows CMD Prompt. 

    Open the command line interface on your computer. This could be a terminal in Linux or Command Prompt or PowerShell in Windows.
    Navigate to the directory where the program_ftdi command or script is located within the xilinx install. You can do this using the cd command followed by the path to the directory. For example:
    cd /Xilinx/Vivado/directory 
    First run the settings64.bat file followed by the program_ftdi command with the -write, -ftdi, -serial, -vendor, -board, and -desc options. For example:
    program_ftdi -write -ftdi FT2232H -serial 0ABC01 -vendor "my vendor co" -board "my board" -desc "my product desc" 

Note: A Vivado full installation should be used for program_ftdi.
